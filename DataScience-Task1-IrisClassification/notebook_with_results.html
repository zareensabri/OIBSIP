Task 1: Iris Flower Classification¶

Author: Zareen Sabri | Track: Data Science | Internship: Oasis Infobyte (OIBSIP)

In this notebook I train a few models to predict the species of an iris flower (setosa, versicolor or virginica) from four measurements: sepal length, sepal width, petal length and petal width.

Steps: look at the data, make some plots, train four classifiers, compare them and pick the best one.

5. Which features matter most?¶

To check this with numbers and not just from the plots, I used the ANOVA F-score from scikit-learn. A higher score means the feature separates the species better.

7. Training the models¶

I trained four classifiers: Logistic Regression, KNN, Decision Tree and Random Forest. Logistic Regression and KNN are in a pipeline with a StandardScaler so the scaler only learns from the training data.

In [9]:
models = {
    "Logistic Regression": make_pipeline(StandardScaler(), LogisticRegression(max_iter=500)),
    "KNN (k=5)":           make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=5)),
    "Decision Tree":       DecisionTreeClassifier(max_depth=3, random_state=42),
    "Random Forest":       RandomForestClassifier(n_estimators=200, random_state=42),
}

results = {}
for name, model in models.items():
    model.fit(X_train, y_train)
    results[name] = model.predict(X_test)
print("All four models trained")

9. Comparing the models¶

The test set only has 30 flowers, so one wrong prediction changes the accuracy by 3.3%. One split is not very reliable for picking a winner, so I also ran 10-fold cross-validation on all 150 rows.

In [12]:
rows = []
for name, model in models.items():
    cv = cross_val_score(model, X, y, cv=10, scoring="accuracy")
    rows.append({
        "Model": name,
        "Test accuracy (20% split)": accuracy_score(y_test, results[name]),
        "10-fold CV mean": cv.mean(),
        "10-fold CV std": cv.std(),
    })

summary = pd.DataFrame(rows).sort_values("10-fold CV mean", ascending=False).reset_index(drop=True)
display(summary.round(4))

summary.set_index("Model")[["Test accuracy (20% split)", "10-fold CV mean"]].plot.barh(figsize=(8, 4))

10. Conclusion¶

Model Test accuracy 10-fold CV
Random Forest 0.900 0.967
Logistic Regression 0.933 0.960
Decision Tree 0.967 0.960
KNN 0.933 0.953

I picked Random Forest as the best model because it has the highest cross-validation score. On the single test split it did worst (3 mistakes out of 30) and the Decision Tree did best, but with only 30 test rows that difference is small and could be luck. Cross-validation uses all the data and is more trustworthy.

All four models are between 95% and 97% in cross-validation, so honestly the difference between them is small. For a real project I would probably use Logistic Regression because it is simpler.

All the mistakes were between versicolor and virginica. Setosa was predicted correctly every time, which matches what the pairplot showed. The Random Forest feature importance also agrees with the F-scores: petal length and petal width matter most and sepal width matters least.

Possible next steps: tune the hyperparameters with GridSearchCV and try using only the petal features.
